# 스타일 메모 (사용자 취향 누적)

사용자가 편집 결과에 준 피드백 중 반복되는 취향을 여기에 기록하고, 다음 편집에 기본으로 적용한다.

## 콘텐츠
- 주력: 후리스 집업 등 의류 코디 쇼츠. 말소리 없이 촬영 → 멘트는 화면 문구(`texts`)로 전달.
- 음악은 넣지 않는다 (업로드 때 앱에서 직접 고르거나 무음). 원본 소리는 `audio: keep`.
- 사용자가 직접 이어붙인 러프컷(여러 착장 + 앞에 인트로)을 주고 "N초짜리로" 요청하는 경우가 많다.
  → 러프컷 맨 앞의 인트로(문구 이미 들어감)는 그대로 살리고, 착장별 베스트 동작만 1~2초씩 골라 정확히 N초로 맞춘다.

## 문구
- 말투: 친근한 반말 ("아직도 고민해?", "알려줄게!", "~까지 OK").
- 스타일: `variety` (검은고딕 + 굵은 외곽선 + 노랑 강조), 얼굴을 가리지 않게 화면 중하단(y 0.58~0.76).
- 착장 섹션마다 노란 박스 해시태그(#데일리룩 #데이트룩 #등산룩) + 본문 한 줄.
- 목록은 한 단어씩 위에서 떨어지며 쌓이고, 새 단어만 노랑 → 흰색으로 남김.

## 컷
- 비슷한 동작(예: 검지 들기 ↔ 양손 가리키기)이 연달아 나오면 "겹친다"고 느낀다 → 동작이 확실히 다른 컷으로.
- 코디 영상은 전신이 보이도록 확대 없이(`zoom: none`), 디테일(하이넥, 소매)은 클로즈업 원본 컷을 쓴다.
